🚀 Atividade – Funcionalidades utilizando AJAX
📚 Sobre o Projeto

Este projeto tem como objetivo desenvolver duas funcionalidades utilizando AJAX (Asynchronous JavaScript and XML) em uma aplicação PHP que utiliza a arquitetura MVC (Model-View-Controller).

As funcionalidades devem utilizar a classe XMLHttpRequest do JavaScript para realizar requisições assíncronas entre o cliente e o servidor, permitindo a troca de informações sem a necessidade de recarregar a página.

🎯 Objetivos
Implementar duas funcionalidades utilizando AJAX.
Utilizar a classe XMLHttpRequest do JavaScript.
Realizar requisições HTTP utilizando os métodos GET e/ou POST.
Trabalhar com envio e recebimento de dados em formato JSON ou texto.
Aplicar o padrão arquitetural MVC no desenvolvimento PHP.
Integrar a aplicação com banco de dados, caso necessário.
⚙️ Requisitos Técnicos
As requisições AJAX podem utilizar os métodos GET e POST.
O envio de dados ao servidor pode ser realizado por parâmetros ou JSON.
As respostas recebidas pelo cliente devem utilizar os formatos texto ou JSON.
O código PHP deve seguir a arquitetura MVC, mantendo a separação entre Model, View e Controller.
Caso sejam utilizadas tabelas no banco de dados, o script SQL de criação deverá fazer parte do projeto.
💡 Exemplos de Funcionalidades

Algumas funcionalidades que podem ser desenvolvidas:

🔽 Carregamento dinâmico de Select: carregar opções de um campo de seleção sem atualizar a página.
✅ Validação de campos: verificar informações preenchidas pelo usuário de forma assíncrona.
💾 Cadastro de dados: salvar uma entidade no banco de dados utilizando AJAX.
🃏 Exibição dinâmica de informações: mostrar dados na tela de acordo com a escolha do usuário, como em cards.
🛠️ Tecnologias Utilizadas
PHP – Desenvolvimento do back-end.
JavaScript – Implementação das requisições AJAX.
XMLHttpRequest – Comunicação assíncrona entre cliente e servidor.
MySQL – Banco de dados (caso necessário).
HTML5 – Estrutura das páginas.
CSS3 – Estilização da aplicação.
MVC – Organização e arquitetura do projeto.
